# 🎓 Educational Project Platform

Платформа для создания и проведения детских образовательных проектов.

## 🚀 Идея

* Родитель (вместе с ребёнком) генерирует идею проекта с помощью ИИ
* Преподаватель создаёт на основе идеи проект
* Назначаются встречи
* Дети записываются и участвуют в проекте

## ✨ Основной функционал

* Генерация идей проектов (AI)
* Создание проектов преподавателями
* Планирование встреч
* Выбор места проведения
* Запись участников на встречи
* Просмотр участников

## 🧱 Стек

* Frontend: React + TypeScript + MUI
* State: React Query
* Backend: (добавь свой стек)
* Карты: Leaflet

## ⚙️ Запуск проекта

```bash
npm install
npm run dev
```

Открыть в браузере:
http://localhost:3000

## 📦 Основные сущности

* Idea — идея проекта
* Project — проект
* Meet — встреча
* Place — место проведения

## 🔄 Основной сценарий

1. Пользователь создаёт или выбирает идею
2. Преподаватель создаёт проект
3. Назначает встречу (дата, место, цена)
4. Участники записываются
5. Проект реализуется через встречи
