# Backend

Используется Express.

Каждый модуль имеет структуру

controller

service

repository

model

dto

---

# Controller

Controller

- получает параметры
- получает body
- вызывает service

Controller не содержит бизнес-логики.

---

# Service

Service

- выполняет проверки
- объединяет несколько Repository
- содержит бизнес-логику

---

# Repository

Repository

- работает только с SQL
- не знает про HTTP
- не содержит бизнес-логики

---

# SQL

Предпочитать понятные запросы.

Избегать сложной генерации SQL.

Использовать параметры вместо конкатенации строк.

---

# Update

Если операция затрагивает несколько таблиц —

координация выполняется через Service.
