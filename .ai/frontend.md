# Frontend

Используется React.

SSR включен.

UI построен на Material UI.

---

# Формы

Используются controlled components.

Каждая форма принимает

values

onChange

onSubmit

Форма не хранит состояние данных.

---

# Структура

Pages

↓

Components

↓

Shared Components

---

# Запросы

Используется TanStack Query.

Запросы располагаются отдельно от компонентов.

---

# MUI

Предпочитать

Stack

Card

Paper

Box

Использовать sx вместо отдельных css-файлов.

---

# Компоненты

Компоненты должны быть максимально простыми.

Сложная логика выносится в hooks или service.
