# Обновление обложки идеи №150

Дата: 13 октября 2026 года. Идея: [Деревянная лира](https://q3-dev.ru/idea/150), постоянный ID `toy-072`.

Новая обложка создана встроенным imagegen: [изображение v2](https://storage.yandexcloud.net/quantum-education/idea-catalog/toy-072-generated-cover-v2.png), [точный промпт, референсы и визуальная проверка](image-prompts/catalog/toy-072-generated-cover-v2.prompt.md). Формат 1536×1024, 3:2. Идентификатор результата: `exec-e655688d-9482-474a-ab7a-aea62a7bbe97`.

Фон и стол сделаны светлее и менее насыщенными; реквизит сокращён до двух небольших групп и отделён свободным столом. Сохранена предложенная конструкция лиры с шестью струнами; число струн не установлено школьной программой. Стиль сверялся с актуальными обложками идей №59, 64, 67 и 65; рабочие копии референсов не входят в публичные файлы приложения.

Через `FileService.uploadBuffer` загружена новая версия; через `IdeaService.importCatalog` обновлена только существующая карточка. API, схема и код приложения не изменены. Каталог синхронизирован. Прежняя обложка v1 сохранена дополнительным изображением с прежним ID.

## Подтверждённые проверки

- Чтение БД до записи, повторная сверка под блокировкой и резервная копия перед изменением; чтение после фиксации.
- Числовой и постоянный ID, название, описание, cardData, catalogMetadata и остальные поля идеи сохранены. Посторонние идеи и фотографии не изменились.
- Две фотографии, ровно одна обложка; старая фотография сохраняет данные, кроме флага isCover и позиции в галерее.
- API `/idea/150` и `/idea/toy-072` возвращают обновлённую карточку.
- Изображение доступно публично, MIME `image/png`, SHA-256 `c8a51bacb7c3d87047bcbbb289372d969bcd1bc885e837fe3aa00ead17542330` совпадает с локальным файлом.
- Страница `/idea/150` отвечает HTTP 200 с правильным заголовком. Локальный рендер настоящего IdeaPage с актуальными данными API подтверждает полное описание, новую основную фотографию, две миниатюры, единственный выбранный кадр и отметку ИИ.
- `npm.cmd run check` завершился с кодом 0: ESLint, TypeScript, сборки client/SSR/server/backend. `git diff --check` и проверка синтаксиса операторского скрипта прошли.

## Ограничение проверки

Визуальная проверка страницы в браузере недоступна: инвентаризация CUA вернула пустые списки apps и browsers. HTTP-проверка и локальный рендер не заменяют эту проверку. Само сгенерированное изображение визуально просмотрено и принято.

Резервные копии и технические результаты находятся в игнорируемой `.cache/idea-150-cover/`: `db-before.json`, `backup-before-write.json`, `catalog-before.json`, `db-after.json`, `api-before.json`, `api-after.json`, `upload.json`, `result.json`, `verification.json` и `render-result.json`. Точная история первой массовой партии сохранена отдельно в прежних отчётах школьной программы.
