# Уведомления

Уведомления хранятся для аккаунта (`passport`) и появляются после успешного сохранения события. Колокольчик показывает число непрочитанных записей. Открытие списка не отмечает их прочитанными: это происходит после перехода по уведомлению, явной отметки или прочтения нового чата.

| Событие | Получатели | Когда создаётся |
| --- | --- | --- |
| Новая заявка на зал | Администраторы выбранного центра | Преподаватель создал встречу со статусом `pending` и запросил зал. |
| Повторная заявка | Администраторы центра новой заявки | Преподаватель изменил время, длительность, зал или центр; бронирование снова перешло в `requested`. |
| Зал подтверждён | Преподаватель встречи | Администратор перевёл заявку в `published` / `confirmed`. |
| Бронирование отменено | Преподаватель, если действие выполнил администратор | Центр отменил бронь; встрече требуется другая площадка. |
| Встреча перенесена | Аккаунты родителей записанных учеников | Изменились дата, время, длительность, зал или центр встречи. |
| Встреча отменена | Аккаунты родителей записанных учеников | Встреча получила статус `cancelled`. Отмена только бронирования описывается отдельно как поиск новой площадки. |
| Новый чат | Второй участник диалога | Отправлено первое сообщение. Открытие пустого чата не уведомляет; последующие сообщения отражаются счётчиком переписки. |
| Возврат оплаты | Получатели, определённые процессом возврата | Возврат поставлен в очередь, завершён или требует внимания. |

Автор действия исключается из получателей. Ключ события уникален для получателя и предотвращает повторную запись при повторном запросе. Ранее созданные уведомления об отдельных сообщениях остаются в истории, но новые больше не создаются.
