Идея «Лук из деревянной ламели» и её обложка **не созданы**. План ссылается на описание пользователя, но самого описания в переданном контексте и локальных материалах нет. Текст запрошен в ходе работы. По одному названию нельзя достоверно воспроизвести предложенную конструкцию; крепление плеч, их размеры и натяжение не придуманы.

После получения текста нужно отделить подтверждённые детали от предположений, создать иллюстрацию предлагаемого варианта, проверить дубль, добавить постоянный ID и выполнить предварительный/транзакционный импорт.

## Интерфейс и кабинеты

- Пустой блок идей на публичной странице преподавателя скрыт; отступ заголовок–содержимое секций — 16 px.
- В проектах центра доступны карточки и таблица; `view=group` открывается карточками с сохранением других параметров URL. На других страницах группировка сохранена.
- Адрес в карточках и таблице сокращён одной строкой; полный текст открывается наведением, фокусом и нажатием. В деталях проекта адрес полный и выход доступен в меню. Из списочных карточек выход убран; прежняя иконка чата сохранена.
- У заявки встречи один чип «На подтверждении» и действия подтверждения/отклонения, без нулевого количества записей и заполненности. У опубликованной действующей встречи управляемого центра — «Подтверждена» с галочкой. Прошедшие/отменённые встречи сохраняют свои статусы. Формат количества — «Записано N» либо «Записано N из M»; заполненность только с лимитом. Подсказки формы сохранены.
- Временные чипы — только «Сегодня»/«Завтра» по Москве. Информационные даты опускают текущий московский год; диапазоны через Новый год содержат оба года. Формы, платёжные документы и выгрузки не менялись.
- Фото преподавателя центра слева от текста и действий, включая телефон. Создание проекта внутри «Мои проекты» после переключателей; в пустом состоянии одно основное действие. Кнопка «Найти» не сжимается и не переносится.
- Список и счётчик учеников используют `StudentAccessService.forPlace`: уникальные активные дети с записью на опубликованную не удалённую встречу фактического центра, без ограничения по дате. Связь только через преподавателя и запись в другом центре не учитываются. На рабочих данных центра 597 оба результата — **0**. Это записи, не явка; платежи не названы балансом. Поиск, ближайшее/последнее занятие, история и учёт явки остаются дальнейшими функциями.
- `/teacher/ideas` возвращает отдельный публичный DTO: идея, ребёнок, связанные проекты, отдельные признаки записи в проект/встречи, доступность контакта. Дети выбираются через `teacherUser`, проекты и встречи преподавателя; авторство родителя не исключает идею. Данные получаются пакетно. Карточка показывает обложку, настоящее фото, возраст, дату, давность и проекты; не объявляет идею выполненной или интерес актуальным.
- `POST /user/:id/parent-conversation` определяет родителя на сервере и при каждом открытии проверяет связь с преподавателем либо управляемым центром. Используется прежняя блокировка пары от дублей личного диалога. Контакт в списке учеников центра также работает. Сообщение автоматически не отправляется.

## Повтор и восстановление

CLI: [update-center-learning-content.ts](../scripts/update-center-learning-content.ts).

```powershell
npm.cmd run build:demo-cli
node .cache/demo/cli/scripts/update-center-learning-content.js
node .cache/demo/cli/scripts/update-center-learning-content.js --apply
```

Без флагов CLI только читает и откатывает транзакцию. Манифест S3 хранится в репозитории. Повторная загрузка (`--upload`) требует исходников в `.cache/content-update/`, файла `sources.json` с полями `id`, `title`, `url` из манифеста и `stool-cover-v1.png`. Промпт встроенного imagegen сохранён в `docs/image-prompts/catalog/stool-carry-handle-v1.md`; локальная обложка — `.cache/content-update/stool-cover-v1.png`.

После разрыва связи сначала прочитать состояние, не повторять запись вслепую. Для адресного восстановления использовать `before.json`: вернуть только `locationId` затронутых проектов/встреч; созданные фотографии/идею/зал удалять только после проверки новых связей. Таблицы целиком не заменять. Локальный каталог после COMMIT восстанавливается из `catalog-after.json` операции.
