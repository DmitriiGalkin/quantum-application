### Общие рекомендации

Для соединения ученика с собственной работой необходима тишина во время работы (без болтовни).

В начальной школе давать детям заготовки для работ не из досок и бруса, а из брёвен, пеньков и спилов. Начиная с 1-го класса после обработки работы шкуркой не должно оставаться следов пилы.

Каждому ученику в классе в начале учебного года необходимо закрепить своё рабочее место в мастерской.

При изготовлении деревянных изделий для пищи не желательно использовать хвойные породы. Лучше яблоня, вишня, груша и любые фруктовые породы.

Знакомство с электроинструментом начинать не раньше 9 класса.

Для нагрева меди вместо горна можно использовать походную газовую горелку или муфельную печь для обжига.
