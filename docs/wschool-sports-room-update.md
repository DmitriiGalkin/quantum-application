# Спортивный зал и уведомления Дмитрия А. — 21 октября 2026

Четыре новых снимка из папки Google Drive «Живой источник» добавлены в галерею спортивного зала №8 центра №597. Оригиналы загружены в S3 и проверены повторным чтением по SHA-256. Источники, контрольные суммы и публичные адреса сохранены в [манифесте](wschool-sports-room-photos.json). В MySQL созданы записи `placeLocationPhoto` №32–35 с позициями 0–3.

Для аккаунта Дмитрия А. №42 созданы пять демонстрационных уведомлений: три непрочитанных (новые фотографии, карточка центра, профиль преподавателя) и два прочитанных (проекты центра, раздел уведомлений). Записи №8–12 имеют стабильные `eventKey`; повторный запуск скрипта не должен их дублировать. Уведомления помечены как уже отправленные, чтобы фоновая доставка push не создавала ложных оповещений. Сразу после транзакции скрипт повторно прочитал все четыре фотографии и пять уведомлений с нужными `readAt`.

Операция выполняется скриптом [add-sports-room-photos-and-notifications.mjs](../scripts/add-sports-room-photos-and-notifications.mjs). Для повторной проверки: `node scripts/add-sports-room-photos-and-notifications.mjs --state`. При временном обрыве связи с MySQL сначала проверять фактическое состояние, затем решать, нужен ли повтор `--apply`.
