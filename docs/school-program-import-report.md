## Проверки и резервные копии

- Перед записью повторное чтение подтвердило неизменность 32 идей и 40 фотографий относительно исходного снимка. Каждая операция имела проверку текущего состояния и резервную выгрузку внутри той же транзакции.
- Исходная резервная копия: `.cache/school-program/backups/2026-10-12T21-25-30-393Z-idea-49/backup.json`. Дополнительные копии каждой адресной операции — в .cache/school-program/backups/. Снимки до и после — db-before.json и db-after.json в .cache/school-program/. Реквизиты подключения в них не сохранялись.
- Итог БД: 96 идей, 111 фотографий. Все прежние числовые и постоянные ID, владельцы, описания и 40 ID фотографий сохранены. 27 незатронутых идей остались без изменений. У каждой новой или обновлённой карточки ровно одна обложка.
- FileService загрузил 70 новых файлов. Публичные GET подтвердили MIME и SHA-256. Все 13 прежних фотографий и обложек обновлённых карточек доступны и побайтно совпадают с копиями до импорта.
- Публичный API https://q3-dev.ru:4000 подтвердил данные и галереи, числовые и постоянные ID, метаданные и наличие новых карточек в списке. Проверены 71 карточка и соответствующие страницы https://q3-dev.ru: HTTP 200 и актуальные SSR-заголовки.
- Рендер IdeaPage с данными публичного API проверен для 71 карточки: названия, полные описания, обложки, порядок миниатюр и пометка ИИ. Опубликованный компонент также содержит галерею и пометку генерации. Это проверка содержимого и разметки, не визуальная проверка браузером.
- Валидатор каталога: 73 идеи, 109 фотографий в items; legacyIdeas содержит ещё №49 и две фотографии. Ссылки, постоянные ID, покрытие и сохранность исходного текста проверены.
- npm.cmd run check прошёл: ESLint, TypeScript, клиентская, SSR, серверная и backend-сборки. Публичные API, типы и схема БД не менялись.

Во время загрузки произошёл сетевой таймаут; повторный запуск сначала читал хранилище и сверял байты, затем загружал отсутствующее. В начале применения случились таймауты чтения подключения; после успешного повторного чтения неизменного состояния записи были выполнены один раз. Повторной записи после неизвестного COMMIT не было.

## Заблокированная проверка

Визуальный просмотр страниц в браузере не выполнен: cua.getState() вернул пустые списки apps и browsers. HTTP, API, SSR-заголовки, рендер содержимого и визуальная проверка самих 69 обложек выполнены. Браузерную проверку не считаем завершённой.
