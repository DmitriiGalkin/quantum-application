# Рекламные ссылки проектов и статистика центра

Основная гипотеза: преподаватель продвигает конкретный проект или кружок с ближайшей подтверждённой встречей. Ссылка ведёт на страницу проекта, где родитель видит место, время, стоимость и запись. Страница преподавателя помогает установить доверие, но не служит основной посадочной страницей для объявления о занятии. Центр тоже может рекламировать проект своего преподавателя; у ссылки сохраняется инициатор.

Преподаватель задаёт название канала в блоке «Реклама проекта» на странице своего проекта. Администратор центра может создать ссылку для проекта этого центра. Для каждого размещения нужна отдельная ссылка; она содержит внутренний токен кампании и UTM параметры. Не публиковать ссылку, пока нет подтверждённой встречи с ясной ценой, местом и свободными местами.

Quantum считает один переход посетителя по одной ссылке в день. Повторный переход в тот же день обновляет время последнего перехода для атрибуции. После успешной записи на встречу того же проекта запись относится к последней рекламной ссылке, открытой этим браузером за предыдущие 7 дней. Отмена записи удаляет связь каскадно; отменённые встречи исключаются из текущего отчёта. Старые записи не атрибутируются задним числом. Метрики доступны преподавателю на странице проекта и администратору центра в `/place/stats`. Хранится случайный идентификатор браузера, без имени и email посетителя.

`/place/stats` показывает за 7, 30 или 90 дней проведённые подтверждённые встречи, действующие записи, известную вместимость, число встреч без вместимости и проекты. Переходы и новые записи по рекламным ссылкам фильтруются по дате события, а число записей дополнительно исключает удалённые записи и отменённые встречи. Историческая посещаемость, выручка и рекламные расходы пока не выводятся: имеющиеся данные не подтверждают эти показатели.

Для владельца сайта Яндекс Метрика может дополнить внутренние данные отчётами по UTM, устройствам, целям и воронкам; интеграция с Директом помогает видеть расходы. При подключении нужно учитывать переходы React Router и отправлять цель после успешной записи. Метрика не является источником цифр в кабинетах преподавателя и центра. Документация: [UTM отчёты](https://www.yandex.ru/support/metrica/ru/reports/tags-utm), [цели](https://yandex.ru/support/direct/ru/statistics/metrika), [воронки](https://yandex.ru/support/metrica/ru/reports/funnels), [расходы](https://yandex.ru/support/metrica/ru/ad/expenses).

Миграция: `node scripts/migrate-project-campaigns.mjs` для предварительного чтения, затем `--apply`. Таблицы: `projectCampaign`, `projectCampaignVisit`, `projectCampaignBooking`. После применения обновить снимок `node export-db-schema.mjs`.
