# Центр «Живой источник»

Помещения центра №597: `npm run db:setup:wschool-rooms` показывает предварительный отчёт; `npm run db:setup:wschool-rooms -- --apply` добавляет отсутствующие активные помещения «мастерская», «актовый зал», «кабинет дополнительный» одной транзакцией. Повторный запуск сохраняет ID. Резервная копия: `.cache/demo/cleanup/wschool-rooms-*/`. Изолированная проверка: `npm run test:wschool-rooms:db` (тот же локальный тестовый сервер, описанный ниже).

`npm run db:setup:wschool` показывает предварительный отчёт. Для записи:

```sh
npm run db:setup:wschool -- --apply
```

CLI использует подключение из `.env`, проверяет фактическую схему, сохраняет затронутые строки в игнорируемую папку `.cache/demo/cleanup/wschool-*/` и выполняет изменения одной транзакцией. После записи читает результат. При потере соединения сначала запустите предварительный отчёт: автоматического повтора записи нет.

Данные реального центра зарегистрированы отдельно от вымышленных демонстрационных наборов: `quantum-wschool-real-v1`. Повторный запуск сохраняет ID и не обновляет существующие записи. Изменённые пользователем записи, неоднозначные совпадения и пересечения расписания требуют проверки оператора.

Администратор и мастер — существующий аккаунт №42 «Дмитрий А.» (Дмитрий Александрович Галкин). Десять остальных преподавателей имеют справочные профили `quantum-directory` без email, токена доступа и вымышленных фотографий. Авторизация таких профилей запрещена.

Центр работает с понедельника по пятницу, 08:00–18:00 МСК. Контакты сохраняются в описании, телефон — также в существующем поле `phone`. Координаты взяты из карты на официальном сайте https://wschool.ru/.

Проект «Деревянный робот — мастерская» использует идею №54 (`toy-001`). Четыре бесплатные опубликованные встречи: 12, 19, 26 октября и 2 ноября 2026 года, 16:00–17:00 МСК. Участники и платежи не создаются.

Новая обложка: `public/catalog/toy-001-generated-cover-v1.png`; запрос и сведения об исходниках: соседний файл `.prompt.md`. Изображение создано встроенным imagegen по фотографиям изделия и загружается через `FileService.uploadBuffer` с постоянным ключом `idea-catalog/toy-001-generated-cover-v1.png`. Восемь исходных фотографий сохраняются в прежнем порядке. Обложка включена в `toy-catalog.json`, поэтому повторный импорт каталога её сохраняет.

Изолированная проверка: `npm run test:wschool:db`. Она использует только MySQL/MariaDB на `127.0.0.1:33079` (переменные `DEMO_TEST_DB_PORT`, `DEMO_TEST_DB_USER`, `DEMO_TEST_DB_PASSWORD`), создаёт отдельную временную БД и проверяет откат, повторный импорт, сохранение посторонних записей и защиту расписания.
