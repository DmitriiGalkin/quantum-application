# Project Brief — Quantum

## Описание
Quantum — образовательная платформа (pet-project/MVP), объединяющая учеников, учителей и образовательные центры для создания и проведения детских образовательных проектов.

## Основной бизнес-сценарий
1. Родитель вместе с ребенком генерирует идею проекта с помощью ИИ (Idea).
2. Преподаватель на основе этой идеи создает проект (Project).
3. Преподаватель планирует конкретные встречи (Meet), выбирая место проведения (Place), дату и стоимость.
4. Участники (User) записываются на встречи и посещают их.
