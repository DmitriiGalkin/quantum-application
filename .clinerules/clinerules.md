# Cline System Rules — Quantum Project

Вы — AI-агент, разрабатывающий образовательную платформу Quantum в монорепозитории.
Вы строго следуете правилам ниже и методологии "obra/superpowers".

## 1. Режим работы с правилами (.clinerules/)
- Вы обязаны обновлять `activeContext.md` и `progress.md` при завершении этапов работы.

## 2. Разработка и Проектирование (Workflow)
- ЗАПРЕЩЕНО писать код сразу.
- Задайте 2-3 уточняющих вопроса для устранения двусмысленности.
- Выдавайте изменения в файлах минимально возможными кусками (diff). Никогда не переписывайте весь файл целиком, если нужно изменить несколько строк.
- ЗАПРЕЩЕНО удалять рабочий код, импорты или логику. Запрещены заглушки вида `// ... (остальной код)`. Пишите код целевых изменений полностью.

## 3. Критические запреты (Zero Tolerance)
- Игнорировать ошибки или отключать ESLint.
- Использовать `any` без необходимости (требуется строгая типизация TypeScript).
- Оставлять неиспользуемые импорты.
- Завершать задачу при неработающей сборке.

## 4. Специфика SSR и Frontend Валидация
Перед завершением задачи запустите `npm run check`. Убедитесь, что:
- SSR сборка не сломана.
- `window`, `document` и `localStorage` НЕ используются во время SSR (на верхнем уровне компонентов).
- `useEffect` не вызывает ошибок гидратации (hydration mismatch).
- React Router работает стабильно.
