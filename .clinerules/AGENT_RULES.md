После каждого изменения кода агент ОБЯЗАН:

Если были изменены файлы в application:
1. Перейди в папку application.
2. Выполни npm run lint.
3. Выполни npm run build.
4. Исправь все ошибки.

Если были изменены файлы в backend:
1. Перейди в папку backend.
2. Выполни npm run lint.
3. Выполни npm run build.
4. Исправь все ошибки.

Не завершай задачу, пока все проверки не будут пройдены.

Запрещено:

- Игнорировать ошибки.
- Отключать ESLint.
- Использовать any без необходимости.
- Оставлять неиспользуемые импорты.
- Завершать задачу при неработающей сборке.

Перед завершением задачи агент обязан проверить:
- SSR не сломан.
- localStorage не используется во время SSR.
- window не используется во время SSR.
- document не используется во время SSR.
- useEffect не влияет на гидратацию.
- Все импорты корректны.
- React Router работает.
- Типы TypeScript не нарушены.
